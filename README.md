# Guess the number

This is a **mini-game** where the user has to guess a number randomly generated by the computer.

---

## 📝 Description

This game has been developed with **IntelliJ IDEA** based on the **MVC architecture**
and has a gaphical user interface.

### 🎯 Game's goal

The computer randomly generates a number between 0 and 100 (called `solutionNumber`).
The user has to guess this number within a limited attempts.

At each attempt, the program indicates if the entered number is :
- **Bigger** than the `solutionNumber`,
- **Smaller** than the `solutionNumber`,
- **Correct** (prints a victory message).

### 📜 Rules

- **Number of games** : the user can restart the game as many times as he wants.
- **Number of rounds** : the user can play up to **3 rounds**.
  He chooses at each end of round if he wants to continue or stop playing.
- **Attempts in a round** : **5 attempts** maximum each round.
- **Score system** :
    - If the user finds at the **first attempt**, the score of this round is 10.
    - The score starts at 4 and decreases by 1 at each attempt performed.  
      *(Examples : if the user finds in 2 attempts,
      the score is 4 ; if he finds in 3 attempts, the score is 3, ...)*
    - The **final score** is the addition of the scores of all the played rounds.

### 📌 Features

| Feature               | Description                                              |
|-----------------------|----------------------------------------------------------|
| **Random generation** | Number between 0 and 100.                                |
| **Limited attempts**  | 5 attempts per round.                                    |
| **Multi-rounds**      | Up to 3 rounds, with the choice to continue.             |
| **Score system**      | Based on the number of attempts.                         |
| **Restart button**    | Endless opportunities to start over.                     |
| **JavaFX GUI**        | Intuitive interface to play without touching a terminal. |

## 🚀 Execution

### With Maven and Java 23 (minimum)

1. Clone the repository : `git clone https://github.com/rachel-learns/guess-the-number-gui.git`
2. Execute the command : `mvn javafx:run`

### With an IDE

1. Clone the repository : `git clone https://github.com/rachel-learns/guess-the-number-gui.git`
2. Open the project with your IDE.
3. Compile and execute the main class (`Launcher.java`).

### No prerequisites

1. Download the zip file in the GitHub Releases section.
2. Unzip it.
3. Double-click on the .exe file in the bin/ folder.

## 🧪 Tests

The game logic is covered by unit tests (JUnit 6) :

- The random number generation (`generateRandomNumberTest`)
- The comparison logic (`compareNumberTest`).
- The calculation of the score (`scoreRoundTest`).
- The messages displayed (`messageHintTest`, `messageScoreTest`, `finalMessageScoreTest`).
- The end of a round and a game (`endRoundTest`, `endGameTest`).

Run them with : `mvn test`
